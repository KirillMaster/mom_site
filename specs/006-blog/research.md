## 2. Хранение и редактирование

Критерий: мама пишет сама, без разработчика.

| Критерий | (a) БД + админка, TipTap WYSIWYG | (a') БД + Markdown-textarea | (b) MDX в репо | (c) Headless CMS self-host (Strapi/Directus) | (c') SaaS CMS |
|---|---|---|---|---|---|
| Мама публикует сама | Да, как в Word | Нет: Markdown нетехнику не подходит | Нет: git/PR/CI | Да, но вторая админка | Да |
| Конституция (админка самодостаточна, один контур) | Да | Да | Нет | Нарушает: второй сервис и логин | Нарушает |
| Картинки | Вставка/перетаскивание в S3 | Ручные ссылки | Файлы в репо | Есть | Есть |
| Ссылки на `Artwork` | Нативно, M:N | Нативно | Id вручную | Нужна синхронизация | Нужна синхронизация |
| Затраты | Нет новых сервисов; TipTap только в админке | 0 | 0 | +контейнер, RAM, бэкапы, обновления | Оплата и доступность из РФ под вопросом (не проверено) |
| Скорость MVP | Средняя | Высокая | Высокая | Низкая | Средняя |

Рекомендация: (a) с TipTap.
- Хранение: `BodyHtml`, санитизация на backend (например HtmlSanitizer/Ganss.Xss; белый список `h2,h3,p,ul,ol,li,strong,em,a,img,figure,figcaption,blockquote`). Проще, чем хранить JSON-документ TipTap (KISS). SSR рендерит через `dangerouslySetInnerHTML` только санитизированный HTML.
- В редакторе только H2/H3 (H1 = заголовок статьи), обязательный alt у картинки, вставка из буфера грузит файл в S3 (не base64).
- TipTap подгружается динамически только на странице редактирования, публичный бандл не растёт.
- Запасной вариант, если TipTap окажется тяжёл: блочная форма (заголовок/абзац/картинка+подпись), но кода больше.
- Markdown и MDX отвергнуты по критерию «сама». Headless CMS отвергнута: второй контур и ресурсы при единственном авторе.

## 4. SEO-требования к странице статьи

| Элемент | Требование |
|---|---|
| URL | `/blog` (индекс, пагинация `?page=N`), `/blog/{slug}` (плоско, без дат), `/blog/category/{slug}`. Slug хранится в БД (транслит от заголовка, редактируемый до публикации, затем неизменный). У `Artwork` slug производный, т.к. схему БД там нельзя было менять; здесь новая таблица |
| Title/Description | `SeoTitle` ≤ 60-70, `SeoDescription` ≤ 160-200 символов; по умолчанию из заголовка/анонса, поля в админке свёрнуты |
| H1 | Один, = `Title`; в теле только H2/H3 |
| Canonical | `alternates.canonical` на абсолютный URL без UTM; у страниц пагинации на себя |
| OG/Twitter | `og:type=article`, `article:published_time`, обложка 1200x630 |
| Schema.org | `BlogPosting` (headline, image, datePublished, dateModified, author → Person `@id`, publisher → Organization, mainEntityOfPage, inLanguage ru) + `BreadcrumbList` (Главная > Блог > Рубрика > Статья); на `/blog` тип `Blog`/`CollectionPage` |
| Sitemap | Посты в `sitemap.ts` с реальным `updatedAt`; рубрики; проверить загрузку в Вебмастере |
| RSS | `app/blog/rss.xml/route.ts` (title, link, pubDate, description, enclosure, полный текст) |
| Яндекс Вебмастер | Подтвердить сайт, добавить sitemap, смотреть «Страницы в поиске» и «Запросы» (делает владелец) |
| IndexNow | Поддерживается Яндексом. Ключ-файл `public/{key}.txt`; при публикации/обновлении backend шлёт GET/POST на endpoint Яндекса (до 10 000 URL за запрос). Дёшево |
| Турбо-страницы | Неактуальны: Яндекс объявил закрытие 7.02.2025, прекращено с апреля 2025. Не делать |
| Дзен | Кросспостинг через RSS-импорт в Дзен Студии. Картинки ширина ≥ 700 px; первичная привязка требует нескольких публикаций (источники расходятся по числам: сверить с официальной справкой); правки источника подхватываются только в течение 7 дней после импорта. Публиковать в Дзен после индексации на сайте, чтобы сайт был первоисточником (практика, не гарантия) |
| Перелинковка | Из статьи: на работы и 1-2 статьи; ссылка «Блог» в `Navigation`/`Footer`; из карточек работ позже |
| Рубрики/теги | Только рубрики (5-6) с описанием на странице рубрики; теги не вводить (тонкие дубли) |
| Изображения | `next/image`, обязательный alt, `priority` только у обложки, `sizes`; avif/webp уже включены; обложка ≤ ~200 KB после оптимизации |
| Кэш | SSR с ISR (revalidate ~5 мин) или on-demand revalidate при публикации |
| Индексация | Черновики публично недоступны; пустая рубрика 404 |

## 5. Модель данных и API (минимум)

| Сущность | Поля |
|---|---|
| `BlogPost` | `Id`, `Slug` (unique, ≤120), `Title` (≤200), `Excerpt` (≤300), `BodyHtml` (text), `CoverImagePath` (≤500), `CoverAlt` (≤200), `SeoTitle` (≤70, null), `SeoDescription` (≤200, null), `BlogCategoryId`, `PublishedAt` (null = черновик; будущая дата = отложенная), `CreatedAt`, `UpdatedAt`; время чтения считать на лету |
| `BlogCategory` | `Id`, `Slug`, `Name`, `Description`, `DisplayOrder` |
| `BlogPostArtwork` | `BlogPostId`, `ArtworkId`, `SortOrder` (M:N) |

Позже: связанные статьи, `ArtworkCategoryId` для авто-подборки, счётчик просмотров.

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/public/blog?page&categorySlug` | Список опубликованных (`PublishedAt <= now`) |
| GET | `/api/public/blog/{slug}` | Статья + работы по теме + связанные |
| GET | `/api/public/blog/categories` | Рубрики |
| CRUD | `/api/admin/blog[/{id}]` | JWT, включая черновики и предпросмотр по id |
| POST | `/api/admin/blog/images` | Загрузка картинки для редактора, возвращает URL (`ImageService`, папка `blog`) |
| CRUD | `/api/admin/blog/categories` | Рубрики |

Требования конституции: валидация на backend (P4: длины, уникальность slug, санитизация HTML, тип/размер картинок); unit + integration тесты на каждый эндпоинт, Jest на компоненты, Playwright на флоу «создал-опубликовал-увидел» (P5); файлы ≤ 200 строк, редактор разбить на `PostEditor`, `ArtworkPicker`, `SeoFields`, `CoverUpload`, `PublishBar` (P3).

## 6. Админ-UX для нетехнического пользователя

1. Список статей: заголовок, рубрика, статус (Черновик / Опубликовано / Запланировано), дата, кнопка «Новая статья».
2. Редактор одной страницей сверху вниз: заголовок → обложка (с обязательным описанием картинки) → текст (панель: Заголовок, Подзаголовок, Список, Цитата, Ссылка, Картинка) → анонс → рубрика → «Работы по теме» (сетка миниатюр с поиском) → «Для поисковиков» (свёрнуто, автозаполнено, счётчики символов).
3. Адрес статьи генерируется автоматически и показывается; редактируется до первой публикации.
4. Кнопки: «Сохранить черновик», «Предпросмотр» (как на сайте), «Опубликовать», «Запланировать».
5. Мягкий чек-лист перед публикацией: обложка и alt, анонс, ≥1 работа, объём ≥ ~1500 знаков.
6. Автосохранение черновика в localStorage на случай закрытия вкладки.
7. Подсказки по-русски, без терминов «slug», «canonical».

Лендинг мастер-классов и страница для дизайнеров: отдельные страницы (коммерческий интент), отдельная спека.

## 8. Процесс

| Вопрос | Рекомендация |
|---|---|
| Частота | 3/мес первые 3 мес. (база ≥ 10 материалов, пригодится и для Дзена), далее 2/мес; регулярность важнее объёма |
| Кто пишет | Мама: факты, истории, фото процесса (голосовые/заметки в Telegram) → ИИ-черновик строго на её фактах → мама правит и подтверждает → Кирилл/SMM проверяет SEO-поля. Не публиковать непроверенный ИИ-текст: ошибки о искусстве и Крыме, шаблонность |
| Объём | 1500-3000 знаков истории, 3000-6000 гайды; свои фото вместо стоковых |
| Темы | Wordstat (бесплатно, вход через Яндекс ID): «купить картину маслом», «картина в интерьер», «картины Крыма», «мастер-классы по живописи Севастополь»; регион Севастополь/Крым/Россия; смотреть «Что ещё искали»; затем «Запросы» в Вебмастере. Бэклог на 3 мес. |
| Измерение | Вебмастер (показы, клики, позиции), Метрика (цели: клик CTA, форма контактов); сводка раз в месяц |
| Срок отдачи | Органика на новом контенте нарастает месяцами; оценивать не раньше 3-6 мес. (общая практика, не измерение) |

## 10. Открытые вопросы владельцу

1. Реально ли писать 2-3 статьи в месяц? Готова диктовать голосом?
2. Проводит ли мастер-классы в Севастополе: формат, цена, расписание, нужна ли запись на сайте?
3. Работает ли с дизайнерами интерьеров: условия (комиссия, заказ под проект), нужна ли отдельная страница?
4. Продаёт через сайт (цены у `Artwork` есть) или только через контакт: как должен выглядеть CTA?
5. Есть ли каналы (Дзен, VK, Telegram): нужен ли кросспостинг/автопост?
6. Подтверждён ли сайт в Яндекс Вебмастере, есть ли доступ к Метрике?
7. Название раздела: «Блог», «Заметки художника», «Мастерская»?
8. Можно ли писать про проданные работы (как портфолио без CTA)?
9. Согласие на ИИ-черновики с обязательной правкой? Кто вычитывает SEO-поля?
10. Нужны ли другие языки? (по умолчанию нет)
11. В `StructuredData.tsx` в `sameAs` есть Instagram (Meta в РФ признана экстремистской организацией): оставлять ли ссылку, решить владельцу (при необходимости с юристом).

| R7 | TipTap: `next/dynamic(..., {ssr:false})` только в `app/admin/blog/[id]`; спайк совместимости с Next 14.0/React 18 — первая задача | Публичный бандл не растёт | Блочная форма — запасной вариант |
