# Research — 011 catalog-trust-order

| Вопрос | Решение | Почему | Альтернативы |
|---|---|---|---|
| Где брать оригиналы для перерендера | S3 `artworks/{guid}.ext` (не `watermarked_`), пара с копией по `LastModified` ≤120 с, то же расширение | Оригиналы не записаны в БД, но загружаются в том же запросе прямо перед копией | Хранить хэши (нет данных); перерендер из копии (знак не убрать) |
| Объём перерендера на проде | Пачки `take` ≤100, сначала dry-run | Таймаут nginx; контроль отчёта до изменений | Фоновая задача (лишняя инфраструктура) |
| Идемпотентность | `OriginalPath != null` → пропуск | Простое состояние в БД | Флаг-колонка |
| «Как купить» | `PageContent` how-to-buy/body + публичный GET | Админка страниц уже есть (как privacy) | Отдельная сущность |
| Очистка описаний | Чистая функция по шаблонам начала абзаца, запуск при старте | Идемпотентно, без ручных SQL | Ручная правка в админке (427 работ) |
| Фильтр размера | Большая сторона: S ≤40, M ≤80, L >80 см | Понятно покупателю, совпадает со спекой | По площади |
| Фильтры в URL | query + `router.replace` | Делимые ссылки, back-кнопка | localStorage |
| Изображения главной | `next/image` + `sizes` | Оригиналы S3 тяжёлые (FR-003) | Превью 300px (мало для hero) |
