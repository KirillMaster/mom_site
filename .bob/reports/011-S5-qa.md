- `createdAt: string`
- `updatedAt: string`

## Diagnosis

### Root Cause
The Coder introduced `ExhibitionPhotos.test.tsx` with a `photo()` factory that creates minimal test objects. These objects are cast to `ArtworkDto` (via spread/assignment) without providing required fields. TypeScript strict mode correctly rejects this.

### Where the Defect Lives
- **File:** `frontend/components/about/ExhibitionPhotos.test.tsx`, lines 11–17 (photo factory)
- **Symptom:** All 28 errors report missing `isForSale`, `createdAt`, `updatedAt`, `categoryId`, `images`
- **Impact:** Frontend code cannot build, blocking all frontend QA gates (lint, build)

### Why Jest Tests Pass Despite Failure
Jest uses Babel transpiler + @babel/preset-typescript, which skips type-checking. The tests execute dynamically without strict type validation. However, the QA procedure explicitly requires `npx tsc --noEmit` (strict TypeScript compilation) to pass.
